# Agent Note: 官方 0.2.10 选择性同步与 H6 兼容门禁

Status: implemented

## Problem

本地基于官方885dffb并追加H6 API23兼容；官方v0.2.10增加连接、媒体与诊断能力，同时仍要求API28且带有BYD车辆和多屏功能。直接覆盖会丢失API23 USB、焦点、Base64、服务和VPN缺失窗口处理。

## Decision

按用户授权选择性同步v0.2.10（3e43e25c55921bdf5149f5f92851acf202ed353a），本地源码版本0.2.10-h6/code33（车机最后确认安装包code32，音频候选待验）。97个上游提交均有处置记录，16个通用源码提交落地；纳入有线无热点、USBMUX边界解析、端口回退、媒体metadata/artwork、解码回退、配对恢复、音频诊断及窗口恢复，保留本地API23路径。不纳入BYD车辆联动、停车视频、仪表/多屏地图及样例启动器。详情见[同步契约](../../../../docs/UPSTREAM_SYNC.md)和[机器清单](../../../../docs/upstream-sync.json)。诊断输出同一标签/SHA，CI校验清单、版本、API23/ARM32设置和跨模块NewApi。

探针证据只支持普通USB open、NCM描述符、样本解码和短音。主体对配置选择失败或USBMUX/NCM接口不可用保留可识别ResourceUnavailable状态；GET_CONFIGURATION未证明目标有效时不进入读泵。UI阻止自动重连，并提供拔插后手动重试，不自动强抢内核接口。失败标志按controller代次隔离，重建时重置；缺失VPN窗口必须保持未授权。正式配置按USBMUX+CDC NCM识别，不采用探针首个USBMUX配置。样本通过不视为完整会话通过。

standalone仍要求显式DIPLAY_AUTH_ASSETS_DIR。用户授权离线完成车测包时，选择官方公开v0.2.10发布APK，用发布元数据SHA256核验整包后，prepare_h6_auth.py仅取两个offline-mfi资产写入Git忽略的.private；拒绝错误校验值、重复/缺失或异常大小条目、输出越界及不同输入覆盖。receipt置于资产目录旁边。运行身份不进源码，不自动下载，也不与APK签名混淆。LocalMfiProbe验证本地密钥/证书匹配，最终APK逐字节检查资产；iPhone接受程度单独实测。主体提供VPN重新检查及RESULT_OK再次prepare核验；ACTIVATE_VPN仍为包级外部授权，不由应用提权。

## Existing note audit

[H6一期兼容](../../implemented/feature/2026-10-01-h6-api23-wired-compatibility.md)部分重叠，保留运行时不变量并互链；[临时窗口](../../implemented/process/2026-10-03-h6-temporary-security-probe.md)部分重叠，保留实车证据与恢复事实；安装策略提案属于系统交付问题，不在本次应用同步范围。没有完全吸收的笔记。

## Alternatives considered

- 全量合并官方标签：能完整获得所有功能，但会混入用户不需要的BYD/多屏/车辆档位依赖，增加API23维护面，因此选按提交移植。
- 仅改版本号和USB解析：最小改动，但遗漏媒体、解码及窗口恢复等用户需要的通用改进，也无法说明上游处置，因此记录完整提交分类并移植通用闭环。
- 把运行身份放回源码或放宽source-only门禁：可让任意构建直接连接，但会破坏认证输入的明确选择与公有树边界；因此采用已核验的官方公开APK、本地私有目录和既有standalone任务。
- 等重新连接车机ADB再处理认证：可同时采设备状态，但USB/VPN测试不会产生身份材料；离线即可准备运行输入，车机只留包级授权和实际数据通道验收。

## Testing

shared355/common154，共509项，508通过、1项既有macOS通配绑定跳过、无失败或错误。API23/29窗口和触摸映射、媒体metadata均执行；新增API23配置2占用、setter失败但目标已激活、读回失败、正常setter及UI不自动重试/旧代次失效回归。另含探针描述符快照选6与编号不硬编码，以及VPN假RESULT_OK、外部真实授权、重新检查状态清理测试。mobile lint/assemble、standalone构建及跨模块NewApi检查通过，APKminSdk23/target37、ARM32、v1/v2签名通过。官方APK SHA256与两运行资产匹配，本地6次签名校验通过；最终文件与测试顺序见[实车交接](../../../../docs/android_6/CAR_TEST_2026-10-04.md)。同步清单、公有树和笔记门禁通过。完整车测仍单独记录。

## Consequences

选择性移植保留上游通用修复并减少H6未用的车辆/多屏依赖；代价是维护提交处置清单，后续不能直接全量merge。共享控制器和媒体锁保留代次隔离、音频focus token、API23封装及关闭路径；诊断新增queued-frame字段不替换本地欠载判定。遇到资源不可用改为手动重试，避免持续切换USB但需用户释放原连接。

运行认证的文件缺口已离线补齐，但官方实验身份在手机上的接受程度、主体USB实际配置/claim/queue和正式VPN授权仍待车测。探针失败配置为3，不能外推为主体配置5/6失败。应用代码不能据样本自动宣告修复。未安装APK、未操作车机、未改变root或系统安全策略；保留开始时已存在的未提交工作。下一版标签之前继续按清单审阅，实际新增功能改变一期范围时重访该决定。

H6默认连接仍不驱逐驱动；用户明确确认的单次接口接管及恢复由[授权fd直接解绑](../feature/2026-10-04-h6-usb-fd-disconnect.md)部分扩展此边界。音频未建立与疑似线缆接触问题见[音频/边界诊断](../bug-fix/2026-10-04-h6-carplay-audio-boundary-diagnostics.md)。

主项目同步code32的[NCM可选填充](../bug-fix/2026-10-07-h6-ncm-optional-pad.md)和code33的[静音输入候选](../bug-fix/2026-10-07-h6-silent-audio-input.md)，上游基线及真实麦克风关闭边界保持。
